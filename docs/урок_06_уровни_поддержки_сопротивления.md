# Урок 06: Уровни поддержки и сопротивления в Backtrader

## 1. Краткое резюме

Урок посвящён созданию канальной стратегии, работающей от динамических уровней поддержки и сопротивления. Уровни рассчитываются через поиск максимумов (High) и минимумов (Low) за окно `lookback` баров с помощью метода `.get(size=N)`. Разбирается частая ошибка новичков — расчёт стоп-лосса от `self.position.price` до исполнения ордера. Второй вариант стратегии добавляет трейлинг-стоп, фильтрацию через Stochastic + ADX и вход по паттерну пересечения SMA на нескольких барах.

---

## 2. Ключевые концепции

- **Lookback** — окно баров для поиска экстремумов. Логика запускается только после накопления нужного числа баров: `if len(self) >= self.params.lookback`
- **Метод `.get(size=N)`** — единственный способ получить срез данных в Backtrader. Срезы в стиле pandas (`self.dataclose[-50:-1]`) не работают
- **Resistance / Support** — `resistance = max(self.datahigh.get(size=lookback))`, `support = min(self.datalow.get(size=lookback))`
- **Стоп-лосс от цены входа** — рассчитывается в `notify_order` после `order.Completed` через `order.executed.price * (1 ± stop_loss)`. Не в `next`!
- **Трейлинг-стоп** — `stop_price` обновляется по минимуму текущего бара (`self.datalow[0]`) пока цена идёт в пользу позиции
- **`any()` по нескольким барам** — `any(self.data.close[-i] < self.short_ma[-i] for i in range(1, window+1))` — проверка условия на нескольких предыдущих барах

### Стратегия 1: Базовая (S/R уровни + SMA)

```python
import backtrader as bt

class MyStrategy(bt.Strategy):
    params = (
        ('short_ma', 6),
        ('lookback', 40),
    )

    def __init__(self):
        self.short_ma = bt.indicators.SimpleMovingAverage(self.datas[0], period=self.params.short_ma)
        self.dataclose = self.datas[0].close
        self.dataopen = self.datas[0].open
        self.datalow = self.datas[0].low
        self.datahigh = self.datas[0].high
        self.datavolume = self.datas[0].volume
        self.order = None
        self.buyprice = None
        self.buycomm = None
        self.stop_price = None
        self.take_profit = None

    def log(self, txt, dt=None):
        dt = dt or self.datas[0].datetime.date(0)
        print('%s, %s' % (dt.isoformat(), txt))

    def notify_order(self, order):
        if order.status in [order.Submitted, order.Accepted]:
            return

        if order.status in [order.Completed]:
            if order.isbuy():
                self.log('Покупка выполнена, Цена: %.2f, На сумму: %.2f, Комиссия %.2f' %
                         (order.executed.price, order.executed.value, order.executed.comm))
                self.buyprice = order.executed.price
                self.buycomm = order.executed.comm
            else:
                self.log('Продажа выполнена, Цена: %.2f, На сумму: %.2f, Комиссия %.2f' %
                         (order.executed.price, order.executed.value, order.executed.comm))
            self.bar_executed = len(self)

        elif order.status in [order.Canceled, order.Margin, order.Rejected]:
            self.log('Отмена ордера')

        self.order = None

    def notify_trade(self, trade):
        if not trade.isclosed:
            return
        self.log('Операционная прибыль, Общая %.2f, С учетом комиссии %.2f' %
                 (trade.pnl, trade.pnlcomm))

    def next(self):
        if len(self) >= self.params.lookback:
            resistance = max(self.datahigh.get(size=self.params.lookback))
            support = min(self.datalow.get(size=self.params.lookback))

            if self.position:
                if self.position.size > 0:  # Long
                    if self.data.close[0] >= self.take_profit:
                        self.close()
                        self.log(f"Take Profit достигнут. Закрытие лонга на {self.data.close[0]}")
                    elif self.data.close[0] <= self.stop_price:
                        self.close()
                        self.log(f"Stop Loss достигнут. Закрытие лонга на {self.data.close[0]}")

                elif self.position.size < 0:  # Short
                    if self.data.close[0] <= self.take_profit:
                        self.close()
                        self.log(f"Take Profit достигнут. Закрытие шорта на {self.data.close[0]}")
                    elif self.data.close[0] >= self.stop_price:
                        self.close()
                        self.log(f"Stop Loss достигнут. Закрытие шорта на {self.data.close[0]}")

            elif not self.position and self.short_ma[0] > self.dataclose[0] and self.short_ma[-1] <= self.dataclose[-1]:
                self.order = self.buy()
                self.take_profit = resistance
                self.stop_price = support
                self.log(f"Сигнал на покупку. Лонг на {self.data.close[0]}, Стоп: {self.stop_price}, Тейк: {self.take_profit}")

            elif not self.position and self.short_ma[0] < self.dataclose[0] and self.short_ma[-1] >= self.dataclose[-1]:
                self.order = self.sell()
                self.take_profit = support
                self.stop_price = resistance
                self.log(f"Сигнал на продажу. Шорт на {self.data.close[0]}, Стоп: {self.stop_price}, Тейк: {self.take_profit}")


if __name__ == '__main__':
    cerebro = bt.Cerebro()

    data = df.copy()
    data['datetime'] = pd.to_datetime(data['datetime'])
    data.set_index('datetime', inplace=True)
    data = bt.feeds.PandasData(dataname=data)
    cerebro.adddata(data)

    cerebro.addstrategy(MyStrategy)
    cerebro.addanalyzer(bt.analyzers.PyFolio, _name='PyFolio')
    cerebro.broker.set_cash(100000)
    cerebro.addsizer(bt.sizers.SizerFix, stake=10)
    cerebro.broker.setcommission(commission=0.001)

    print(f"Стартовый баланс: {cerebro.broker.getvalue()}")
    cerebro.run()
    print(f"Итоговый баланс: {cerebro.broker.getvalue()}")
```

### Стратегия 2: Продвинутая (трейлинг-стоп + Stochastic + ADX)

```python
import backtrader as bt

class MyStrategy(bt.Strategy):
    params = (
        ('short_ma', 6),
        ('take_profit', 0.03),
        ('stop_loss', 0.01),
        ('short_stoch', 11),
        ('short_stoch_d', 10),
        ('short_stoch_k', 7),
        ('long_stoch', 100),
        ('long_stoch_d', 19),
        ('long_stoch_k', 8),
        ('upper', 80),
        ('central', 50),
        ('lower', 20),
        ('adx', 11),
        ('adx_level', 24),
        ('lookback_window', 4),  # окно для проверки условий на нескольких барах
    )

    def __init__(self):
        self.short_ma = bt.indicators.SimpleMovingAverage(self.datas[0], period=self.params.short_ma)
        self.short_stoch = bt.indicators.StochasticFull(
            self.datas[0], period=self.params.short_stoch,
            period_dfast=self.params.short_stoch_d, period_dslow=self.params.short_stoch_k)
        self.long_stoch = bt.indicators.StochasticFull(
            self.datas[0], period=self.params.long_stoch,
            period_dfast=self.params.long_stoch_d, period_dslow=self.params.long_stoch_k)
        self.short_stoch_d = self.short_stoch.lines.percD
        self.short_stoch_k = self.short_stoch.lines.percK
        self.long_stoch_d = self.long_stoch.lines.percD
        self.long_stoch_k = self.long_stoch.lines.percK
        self.adx = bt.indicators.AverageDirectionalMovementIndex(self.datas[0], period=self.params.adx)
        self.dataclose = self.datas[0].close
        self.dataopen = self.datas[0].open
        self.datalow = self.datas[0].low
        self.datahigh = self.datas[0].high
        self.datavolume = self.datas[0].volume
        self.order = None
        self.buyprice = None
        self.buycomm = None
        self.stop_price = None

    def log(self, txt, dt=None):
        dt = dt or self.datas[0].datetime.date(0)
        print('%s, %s' % (dt.isoformat(), txt))

    def notify_order(self, order):
        if order.status in [order.Submitted, order.Accepted]:
            return

        if order.status in [order.Completed]:
            if order.isbuy():
                self.log('Покупка выполнена, Цена: %.2f, На сумму: %.2f, Комиссия %.2f' %
                         (order.executed.price, order.executed.value, order.executed.comm))
                # Стоп считается ПОСЛЕ исполнения — от реальной цены входа
                self.stop_price = order.executed.price * (1 - self.params.stop_loss)
                self.buyprice = order.executed.price
                self.buycomm = order.executed.comm
                self.log(f"Открыт лонг на {order.executed.price}, Стоп: {self.stop_price}")
            else:
                self.log('Продажа выполнена, Цена: %.2f, На сумму: %.2f, Комиссия %.2f' %
                         (order.executed.price, order.executed.value, order.executed.comm))
                self.stop_price = order.executed.price * (1 + self.params.stop_loss)
                self.log(f"Открыт шорт на {order.executed.price}, Стоп: {self.stop_price}")
            self.bar_executed = len(self)

        elif order.status in [order.Canceled, order.Margin, order.Rejected]:
            self.log('Отмена ордера')

        self.order = None

    def notify_trade(self, trade):
        if not trade.isclosed:
            return
        self.log('Операционная прибыль, Общая %.2f, С учетом комиссии %.2f' %
                 (trade.pnl, trade.pnlcomm))

    def next(self):
        if self.position:
            if self.position.size > 0:  # Long
                if self.data.close[0] >= self.position.price * (1 + self.params.take_profit):
                    self.close()
                    self.log(f"Take Profit. Закрытие лонга на {self.data.close[0]}")
                elif self.data.close[0] <= self.position.price * (1 - self.params.stop_loss):
                    self.close()
                    self.log(f"Stop Loss. Закрытие лонга на {self.data.close[0]}")
                # Трейлинг-стоп: подтягиваем стоп за минимумом
                elif self.data.close[0] > self.stop_price and self.data.close[0] > self.datalow[0]:
                    if self.datalow[0] > self.stop_price:
                        self.stop_price = self.datalow[0]
                    print(f'New stop: {self.stop_price}')
                elif self.data.close[0] < self.stop_price:
                    self.close()
                    self.log(f'Выход по трейлинг-стопу: {self.dataclose[0]}')

            elif self.position.size < 0:  # Short
                if self.data.close[0] < self.position.price * (1 - self.params.take_profit):
                    self.close()
                    self.log(f"Take Profit. Закрытие шорта на {self.data.close[0]}")
                elif self.data.close[0] > self.position.price * (1 + self.params.stop_loss):
                    self.close()
                    self.log(f"Stop Loss. Закрытие шорта на {self.data.close[0]}")
                # Трейлинг-стоп: подтягиваем стоп за максимумом
                elif self.data.close[0] < self.stop_price and self.data.close[0] < self.datahigh[0]:
                    if self.datahigh[0] < self.stop_price:
                        self.stop_price = self.datahigh[0]
                    print(f'New stop: {self.stop_price}')
                elif self.data.close[0] > self.stop_price:
                    self.close()
                    self.log(f'Выход по трейлинг-стопу: {self.dataclose[0]}')

        # Вход в Long: цена была ниже SMA на нескольких барах, теперь выше
        elif not self.position and \
                (any(self.data.close[-i] < self.short_ma[-i] for i in range(1, self.params.lookback_window + 1))
                 and self.data.close[0] > self.short_ma[0]) \
                and self.short_stoch_k[0] > self.short_stoch_d[0] \
                and self.short_stoch_k[-1] < self.short_stoch_d[-1] \
                and self.long_stoch_k[0] > self.long_stoch_d[0] \
                and self.adx[0] > self.params.adx_level:
            self.order = self.buy()

        # Вход в Short: цена была выше SMA на нескольких барах, теперь ниже
        elif not self.position and \
                (any(self.data.close[-i] > self.short_ma[-i] for i in range(1, self.params.lookback_window + 1))
                 and self.data.close[0] < self.short_ma[0]) \
                and self.short_stoch_k[0] < self.short_stoch_d[0] \
                and self.short_stoch_k[-1] > self.short_stoch_d[-1] \
                and self.long_stoch_k[0] < self.long_stoch_d[0] \
                and self.adx[0] < self.params.adx_level:
            self.order = self.sell()


if __name__ == '__main__':
    cerebro = bt.Cerebro()

    data = df.copy()
    data['datetime'] = pd.to_datetime(data['datetime'])
    data.set_index('datetime', inplace=True)
    data = bt.feeds.PandasData(dataname=data)
    cerebro.adddata(data)

    cerebro.addstrategy(MyStrategy)
    cerebro.addanalyzer(bt.analyzers.PyFolio, _name='PyFolio')
    cerebro.broker.set_cash(100000)
    cerebro.addsizer(bt.sizers.SizerFix, stake=10)
    cerebro.broker.setcommission(commission=0.001)

    print(f"Стартовый баланс: {cerebro.broker.getvalue()}")
    cerebro.run()
    print(f"Итоговый баланс: {cerebro.broker.getvalue()}")
    # cerebro.plot(iplot=False, volume=False)
```

## 4. Важные замечания

- **Срезы только через `.get()`** — `self.dataclose[-50:-1]` не работает. Только `self.datahigh.get(size=50)`
- **Стоп от цены входа — только в `notify_order`** — `self.stop_price = order.executed.price * (1 - stop_loss)` после `order.Completed`. В `next` до исполнения `self.position.price` ещё не задана
- **`bt.sizers.SizerFix`** — синоним `bt.sizers.FixedSize`, оба варианта рабочие
- **`any()` по нескольким барам** — мощный паттерн для фильтрации входов: проверяем условие не на одном баре, а на окне предыдущих
- **ADX как фильтр тренда** — `adx[0] > adx_level` подтверждает наличие тренда перед входом; снижает число ложных сигналов

---

## 5. Шпаргалка

| Действие | Код |
|----------|-----|
| Массив последних N максимумов | `self.datahigh.get(size=N)` |
| Уровень сопротивления | `resistance = max(self.datahigh.get(size=N))` |
| Уровень поддержки | `support = min(self.datalow.get(size=N))` |
| Стоп от цены входа (в notify_order) | `self.stop_price = order.executed.price * (1 - self.params.stop_loss)` |
| Трейлинг-стоп (обновление) | `if self.datalow[0] > self.stop_price: self.stop_price = self.datalow[0]` |
| Проверка условия на N барах | `any(self.data.close[-i] < self.short_ma[-i] for i in range(1, N+1))` |
| Линии стохастика | `self.stoch.lines.percK`, `self.stoch.lines.percD` |
| ADX индикатор | `bt.indicators.AverageDirectionalMovementIndex(self.datas[0], period=N)` |
| Закрытие позиции | `self.close()` |

## 6. Применение в боте (T-Invest API)

- **Динамические каналы** — бот пересчитывает `support` и `resistance` через `.get(size=N)` при каждой новой свече из T-Invest API
- **Стоп после исполнения** — при получении webhook об исполнении ордера берём `order.executed.price`, считаем стоп и сохраняем в переменную. Только тогда отправляем стоп-приказ
- **Трейлинг-стоп локально** — хранить стоп в памяти бота, обновлять по минимуму/максимуму бара. При пробое — рыночный ордер на закрытие через T-Invest API
- **`any()` по нескольким барам** — при работе с потоком тиков из WebSocket формируем буфер последних N свечей и применяем тот же паттерн
