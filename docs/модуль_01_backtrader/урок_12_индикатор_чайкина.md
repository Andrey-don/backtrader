# Урок 12: Кастомный индикатор Чайкина для Backtrader

## 1. Краткое резюме

Урок посвящён реализации индикатора Чайкина (Chaikin Oscillator) как кастомного `bt.Indicator` и стратегии на его основе. Индикатор измеряет накопление/распределение объёма и вычисляется как разность EMA(3) и EMA(10) от линии ADL. Стратегия комбинирует три подтверждения: EMA-кроссовер, RSI, нулевой кросс Чайкина. Выход — по Стохастику.

---

## 2. Ключевые концепции

- **ADL (Accumulation/Distribution Line)** — накопленная сумма денежного потока: `mfm × volume`, где `mfm = [(close - low) - (high - close)] / (high - low)`
- **`bt.DivByZero(a, b, zero=0.0)`** — защита от деления на ноль (high == low)
- **`bt.indicators.Accum(line)`** — кумулятивная сумма линии (аналог `.cumsum()` в pandas)
- **Тройное подтверждение** — EMA кроссовер + RSI выше 50 + Чайкин переходит через ноль
- **Выход по Stochastic** — `stochastic.percD` падает ниже 75

## 3. Код урока

```python
import backtrader as bt
import pandas as pd


class ChaikinOscillator(bt.Indicator):
    """
    Chaikin Oscillator = EMA(short) от ADL - EMA(long) от ADL
    ADL = накопленная сумма (Money Flow Multiplier × Volume)
    """
    lines = ('chaikin', 'adl')
    params = (
        ('short_period', 3),
        ('long_period', 10),
    )

    def __init__(self):
        # Money Flow Multiplier
        numerator = (self.data.close - self.data.low) - (self.data.high - self.data.close)
        denominator = self.data.high - self.data.low
        mfm = bt.DivByZero(numerator, denominator, zero=0.0)

        # Money Flow Volume
        mfv = mfm * self.data.volume

        # ADL — кумулятивная сумма денежного потока
        self.lines.adl = bt.indicators.Accum(mfv)

        # Chaikin Oscillator = EMA(3) - EMA(10) от ADL
        self.lines.chaikin = (
            bt.indicators.EMA(self.lines.adl, period=self.p.short_period) -
            bt.indicators.EMA(self.lines.adl, period=self.p.long_period)
        )


class EMARSIChaikinStochasticStrategy(bt.Strategy):
    params = (
        ('ema_period', 5),
        ('rsi_period', 14),
        ('short_period', 3),    # для ChaikinOscillator
        ('long_period', 10),    # для ChaikinOscillator
        ('stoch_k', 21),
        ('stoch_d', 6),
        ('stoch_slow', 6),
    )

    def log(self, txt, dt=None):
        dt = dt or self.datas[0].datetime.date(0)
        print('%s, %s' % (dt.isoformat(), txt))

    def __init__(self):
        self.ema = bt.indicators.EMA(self.data.close, period=self.params.ema_period)
        self.rsi = bt.indicators.RSI(self.data.close, period=self.params.rsi_period)
        self.chaikin = ChaikinOscillator(self.data,
                                         short_period=self.params.short_period,
                                         long_period=self.params.long_period)
        self.stochastic = bt.indicators.Stochastic(self.data,
                                                    period=self.params.stoch_k,
                                                    period_dfast=self.params.stoch_d,
                                                    period_dslow=self.params.stoch_slow)
        self.order = None

    def notify_order(self, order):
        if order.status in [order.Submitted, order.Accepted]:
            return
        if order.status in [order.Completed]:
            if order.isbuy():
                self.log('BUY EXECUTED, %.2f' % order.executed.price)
            elif order.issell():
                self.log('SELL EXECUTED, %.2f' % order.executed.price)
        self.order = None

    def next(self):
        if len(self) < 5 or self.order:
            return

        self.log('Close: %.2f, EMA: %.2f, RSI: %.2f, Chaikin: %.2f' %
                 (self.data.close[0], self.ema[0], self.rsi[0], self.chaikin.chaikin[0]))

        # Три сигнала на вход в лонг
        ema_long = self.data.close[0] > self.ema[0] and self.data.close[-1] < self.ema[-1]
        rsi_long = self.rsi[0] > 50 and self.rsi[-1] < 50
        chaikin_long = self.chaikin.chaikin[0] > 0 and self.chaikin.chaikin[-1] < 0

        if not self.position:
            if ema_long and rsi_long and chaikin_long:
                self.log('BUY CREATE, %.2f' % self.data.close[0])
                self.order = self.buy()

        elif self.position:
            # Выход: stochastic.percD пробивает 75 сверху вниз
            if self.stochastic.percD[0] < 75 and self.stochastic.percD[-1] > 75:
                self.log('SELL CREATE, %.2f' % self.data.close[0])
                self.order = self.sell()


if __name__ == '__main__':

    cerebro.addstrategy(EMARSIChaikinStochasticStrategy)

    cerebro.addsizer(bt.sizers.FixedSize, stake=1)
    cerebro.broker.setcommission(commission=0.005)

    print('Стартовый портфель: %.2f' % cerebro.broker.getvalue())
    cerebro.run()
```

## 4. Важные замечания

- **`bt.indicators.Accum`** — встроенный оператор кумулятивной суммы. Аналог `cumsum()` в pandas, но для Backtrader-линий
- **`bt.DivByZero(a, b, zero=0.0)`** — обязателен при вычислении MFM: если `high == low`, знаменатель ноль
- **Доступ к линии** — `self.chaikin.chaikin[0]` (имя линии через точку, затем индекс). Аналогично: `self.chaikin.adl[0]`
- **`stochastic.percD`** а не `stochastic[0]`** — `stochastic[0]` вернёт `percK`. Для сигнальной линии нужен явный `.percD`
- **3 подтверждения** — каждый кроссовер проверяется как «текущий > порога И предыдущий < порога» (именно на этом баре произошло пересечение)

## 5. Шпаргалка

| Действие | Код |
|----------|-----|
| Накопленная сумма линии | `bt.indicators.Accum(mfv)` |
| Защита от деления на 0 | `bt.DivByZero(num, denom, zero=0.0)` |
| Доступ к именованной линии | `self.chaikin.chaikin[0]`, `self.chaikin.adl[0]` |
| EMA от кастомной линии | `bt.indicators.EMA(self.lines.adl, period=N)` |
| Кроссовер через ноль | `chaikin[0] > 0 and chaikin[-1] < 0` |
| Stochastic percD | `self.stochastic.percD[0]` |

## 6. Применение в боте (T-Invest API)

- **Чайкин как фильтр объёма** — подтверждает вход только когда объём поддерживает направление движения (накопление или распределение)
- **Тройное подтверждение** — снижает количество ложных входов за счёт требования трёх одновременных сигналов. Подходит для волатильных инструментов
- **Оптимизация периодов** — `short_period`, `long_period`, `stoch_k`, `stoch_d` — все в `params`, готовы для Optuna
