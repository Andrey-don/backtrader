# Урок 14: Адаптивная стратегия для Backtrader

## 1. Краткое резюме

Урок посвящён созданию адаптивных торговых стратегий, которые умеют подстраиваться под текущую волатильность и фазу рынка, не полагаясь на жёстко заданные параметры. Рассматривается расчёт адаптивной скользящей средней (KAMA) и адаптивного осциллятора RSI. Также демонстрируется процесс разделения исторических данных на несколько периодов (кросс-валидация) с помощью библиотеки sklearn для проверки устойчивости стратегии на разных участках рынка перед запуском реального бота.

---

## 2. Ключевые концепции

- **KAMA (Kaufman's Adaptive Moving Average)** — адаптивная скользящая средняя, которая быстрее реагирует на направленный тренд и замедляется во время флэта (боковика). В расчётах используются: коэффициент эффективности (ER) и константа сглаживания (SC).
- **Адаптивный RSI** — индикатор относительной силы, период которого не фиксирован (например, 14), а динамически изменяется в зависимости от текущей рыночной волатильности (стандартного отклонения цен).
- **TimeSeriesSplit** — инструмент из библиотеки sklearn, который разбивает временной ряд на несколько последовательных частей (фолдов). Позволяет провести бэктест стратегии на разных независимых периодах рынка.
- **Сигналы** — базовая логика: если цена закрытия выше KAMA → покупка (1), если ниже → продажа (−1).

## 3. Код урока

```python
import pandas as pd
import numpy as np
import warnings
from sklearn.model_selection import TimeSeriesSplit

warnings.filterwarnings('ignore')

# Загрузка данных (gas.csv — фьючерс на газ, 5000 баров, 2005–2024)
data = pd.read_csv('gas.csv')
data['Date'] = pd.to_datetime(data['Date'])
data = data.sort_values('Date')


def calculate_kama(data, window=10, fast_period=2, slow_period=30):
    """KAMA — адаптивная скользящая средняя Кауфмана."""
    er = abs(data['Close'] - data['Close'].shift(window)) / data['Close'].diff().abs().rolling(window).sum()
    er = er.fillna(0)
    sc = (er * (2 / (fast_period + 1) - 2 / (slow_period + 1)) + 2 / (slow_period + 1)) ** 2
    kama = [data['Close'].iloc[0]]
    for i in range(1, len(data)):
        kama.append(kama[-1] + sc.iloc[i] * (data['Close'].iloc[i] - kama[-1]))
    data['KAMA'] = kama
    return data


def adaptive_rsi(data, base_period=14, volatility_factor=5):
    """Адаптивный RSI с переменным периодом на основе волатильности.
    
    ВНИМАНИЕ: в оригинале урока есть баг — rs является Series, а не скаляром.
    Исправленная версия использует .iloc[i] для извлечения скалярного значения.
    """
    vol = data['Close'].rolling(volatility_factor).std()
    adaptive_period = base_period + vol / vol.mean() * base_period
    adaptive_period = adaptive_period.fillna(base_period)
    rsi = []
    for i in range(len(data)):
        period = max(2, int(adaptive_period.iloc[i]))
        gains = data['Close'].diff().clip(lower=0).rolling(period).sum()
        losses = -data['Close'].diff().clip(upper=0).rolling(period).sum()
        # ИСПРАВЛЕНО: было rs = gains / losses (Series), нужно .iloc[i]
        rs_val = gains.iloc[i] / losses.iloc[i] if losses.iloc[i] != 0 else 0
        rsi.append(100 - (100 / (1 + rs_val)) if losses.iloc[i] != 0 else 100)
    data['Adaptive_RSI'] = rsi
    return data


def generate_signals(data):
    """Сигналы на основе KAMA."""
    data['Signal'] = 0
    data.loc[data['Close'] > data['KAMA'], 'Signal'] = 1   # покупка
    data.loc[data['Close'] < data['KAMA'], 'Signal'] = -1  # продажа
    return data


def backtest(data):
    """Бэктест: кумулятивная доходность стратегии."""
    data['Strategy_Return'] = data['Signal'].shift(1) * data['Close'].pct_change()
    cumulative_return = (1 + data['Strategy_Return']).cumprod()
    return cumulative_return


# Применение индикаторов
data = calculate_kama(data)
data = adaptive_rsi(data)
data = generate_signals(data)

# Кросс-валидация на 5 периодах
tscv = TimeSeriesSplit(n_splits=5)
results = []
for train_index, test_index in tscv.split(data):
    train, test = data.iloc[train_index], data.iloc[test_index]
    test = backtest(test)
    results.append(test.iloc[-1])

print("Результаты стратегии на 5 периодах:", results)
# Оригинальный вывод: [0.137, 0.389, 0.646, 0.857, 0.200] — все < 1.0, стратегия убыточна
```

---

## 4. Важные замечания

### Результаты бэктеста — автор урока ошибается
Спикер интерпретирует результаты `[0.137, 0.389, 0.646, 0.857, 0.200]` как прибыль («здесь 13,7%, здесь 38,9%... В целом она всегда показывает плюс»). **Это неверно.**

`cumprod()` считает накопительное произведение капитала, где старт = 1.0 (100%):
- `0.137` → осталось 13.7% депозита → убыток **−86.3%**
- `0.857` → осталось 85.7% депозита → убыток **−14.3%**
- Все 5 периодов убыточны.

### Почему стратегия убыточна — логика, не баг
Стратегия использует примитивный подход: сигнал только по пересечению цены и KAMA. В периоды флэта (боковика) цена многократно пересекает линию туда-обратно → десятки ложных входов (whipsawing) → накопленный убыток.

### Баг в adaptive_rsi (не влияет на результат в данном уроке)
`rs = gains / losses` — это Series, а не скаляр. В массив `rsi` добавляются объекты Series, а не числа. Колонка `Adaptive_RSI` заполняется некорректно. **Однако** в `generate_signals` эта колонка не используется — сигналы считаются только по KAMA, поэтому баг не влияет на итоговые `results`.

## 5. Шпаргалка

| Действие | Код |
|----------|-----|
| Разбить ряд на 5 частей | `tscv = TimeSeriesSplit(n_splits=5)` |
| Итерация по фолдам | `for train_index, test_index in tscv.split(data):` |
| Начальное значение KAMA | `kama = [data['Close'].iloc[0]]` |
| Сигнал покупки по KAMA | `data.loc[data['Close'] > data['KAMA'], 'Signal'] = 1` |
| Доходность свечи | `data['Close'].pct_change()` |
| Кумулятивная доходность | `(1 + data['Strategy_Return']).cumprod()` |
| Исправленный rs (скаляр) | `gains.iloc[i] / losses.iloc[i]` |

2. **Усложнить сигналы:** добавить Adaptive RSI как фильтр — покупать только когда цена выше KAMA **И** RSI подтверждает тренд

## 7. Применение в боте T-Invest API

- **KAMA как трендовый фильтр:** пересчитывать на каждой новой закрытой свече из T-Invest API. Ордер отправлять только при пересечении цены и линии KAMA.
