# Урок 10: Выход по цене стопа в Backtrader

## 1. Краткое резюме

Урок объясняет проблему исполнения стоп-ордеров в Backtrader: по умолчанию все ордера исполняются на **открытии следующего бара**, а не в момент пробоя уровня. Рассматриваются три способа получить исполнение по цене стопа: `cheat_on_close`, `bt.Order.Stop` и `set_slippage_fixed(0)`.

---

## 2. Ключевые концепции

- **Проблема**: в стандартном режиме стоп срабатывает на открытии следующего бара — цена может значительно уйти от уровня стопа
- **`cheat_on_close=True`** — `cerebro = bt.Cerebro(cheat_on_close=True)` — разрешает исполнять ордера по цене закрытия текущего бара
- **`bt.Order.Stop`** — стоп-ордер: становится рыночным при достижении указанной цены. Наиболее правильный способ
- **`set_slippage_fixed(0)`** — устанавливает нулевое проскальзывание, минимизируя отклонение цены исполнения

---

## 3. Код урока

### Способ 1: cheat_on_close

```python
import backtrader as bt

# Исполнение на цене закрытия текущей свечи (не открытии следующей)
cerebro = bt.Cerebro(cheat_on_close=True)
```

### Способ 2: bt.Order.Stop (рекомендуется)

```python
import backtrader as bt


class TestStrategy(bt.Strategy):
    params = dict(stop_loss=0.02)  # 2% стоп-лосс

    def __init__(self):
        self.dataclose = self.data.close
        self.order = None

    def next(self):
        if self.order:
            return

        # Покупка по простому условию
        if self.dataclose[0] > self.dataclose[-1]:
            self.order = self.buy()
            stop_price = self.dataclose[0] * (1 - self.params.stop_loss)
            # Стоп-ордер — исполнится в момент пробоя уровня
            self.sell(exectype=bt.Order.Stop, price=stop_price)

    def notify_order(self, order):
        if order.status in [order.Completed]:
            if order.isbuy():
                print(f"Куплено по {order.executed.price}")
            elif order.issell():
                print(f"Продано по {order.executed.price}")


if __name__ == '__main__':
    cerebro = bt.Cerebro()
    cerebro.addstrategy(TestStrategy)

    # Способ 3: нулевое проскальзывание
    cerebro.broker.set_slippage_fixed(0)

    cerebro.broker.setcash(100000.0)
    cerebro.run()
```

---

## 4. Важные замечания

- **Реализм vs точность** — `cheat_on_close` даёт точное исполнение, но нереалистично: в жизни нельзя гарантированно купить/продать по цене закрытия
- **`bt.Order.Stop` — наилучший вариант** — максимально приближен к реальному поведению биржи. Ордер становится рыночным при пробое уровня
- **Конкуренция стоп и тейк** — если выставлены оба (stop + limit), при срабатывании одного второй нужно отменять через `self.cancel()`

---

## 5. Шпаргалка

| Действие | Код |
|----------|-----|
| Режим cheat_on_close | `cerebro = bt.Cerebro(cheat_on_close=True)` |
| Стоп-ордер | `self.sell(exectype=bt.Order.Stop, price=stop_price)` |
| Лимитный ордер | `self.sell(exectype=bt.Order.Limit, price=tp_price)` |
| Нулевое проскальзывание | `cerebro.broker.set_slippage_fixed(0)` |
| Отмена ордера | `self.cancel(order_obj)` |

---

## 6. Применение в боте (T-Invest API)

- **В live-торговле проблемы нет** — T-Invest исполняет стоп-заявки по биржевой цене пробоя. Это поведение `bt.Order.Stop` по умолчанию
- **При бэктестинге** — использовать `bt.Order.Stop` чтобы результаты бэктеста максимально совпадали с реальным исполнением
- **`cheat_on_close`** — только для быстрых экспериментов, не для финальной оценки стратегии
