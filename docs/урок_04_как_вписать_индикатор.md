# Урок 04: Как вписать индикатор в Backtrader

## 1. Краткое резюме

Урок подробно разбирает механику подключения и настройки встроенных индикаторов (SMA, EMA, RSI, Stochastic) в стратегиях Backtrader. Основной акцент делается на умении находить нужные параметры через исходный код библиотеки на GitHub. Рассматривается инициализация параметров в блоке `__init__`, работа с кроссами (точками пересечения уровней) и создание универсального шаблона метода `next` для отработки сигналов как в лонг (Buy), так и в шорт (Sell).

---

## 2. Ключевые концепции

- **Чтение исходников на GitHub** — репозиторий Backtrader, папка `indicators`. Смотреть `params` (требуемые настройки, например `period`) и `lines` (названия возвращаемых линий)
- **Инициализация в `__init__`** — все индикаторы объявляются через `self` ровно один раз; движок сам пересчитывает их на каждой новой свече
- **Шаблон «перевёртыш»** — структура `next`, позволяющая торговать в обе стороны: `if not self.position` → вход, `if self.position.size > 0` → управление лонгом, `elif self.position.size < 0` → управление шортом
- **Кроссы (пересечения)** — `bt.indicators.CrossOver` возвращает `1` (пересечение снизу вверх) или `-1` (сверху вниз), формируя чёткий триггер для сделки
- **Передача данных** — при одном активе в индикатор можно передавать `self.data` или `self.datas[0]` — движок поймёт автоматически

---

## 3. Код урока

```python
import backtrader as bt

class TestStrategy(bt.Strategy):
    params = (
        ('period_sma', 37),
        ('period_rsi', 15),
        ('overbought', 75),
        ('oversold', 25),
        ('period_k', 14),
        ('period_dfast', 3),
    )

    def __init__(self):
        self.dataclose = self.datas[0].close
        self.order = None

        # 1. Простая скользящая средняя
        self.sma = bt.indicators.SMA(self.datas[0], period=self.params.period_sma)

        # 2. RSI
        self.rsi = bt.indicators.RSI(self.datas[0], period=self.params.period_rsi)

        # 3. Кроссы RSI с уровнями перекупленности / перепроданности
        self.cross_up_rsi = bt.indicators.CrossOver(self.rsi, self.params.overbought)
        self.cross_down_rsi = bt.indicators.CrossOver(self.rsi, self.params.oversold)

        # 4. Стохастик
        self.stochastic = bt.indicators.Stochastic(
            self.datas[0],
            period=self.params.period_k,
            period_dfast=self.params.period_dfast
        )

    def next(self):
        if not self.position:
            # Вход в Long: цена выше SMA и RSI пересёк уровень overbought снизу вверх
            if self.dataclose[0] > self.sma[0] and self.cross_up_rsi[0] == 1:
                self.order = self.buy()

            # Вход в Short: цена ниже SMA и RSI пересёк уровень oversold сверху вниз
            elif self.dataclose[0] < self.sma[0] and self.cross_down_rsi[0] == -1:
                self.order = self.sell()

        else:
            # Выход из Long
            if self.position.size > 0:
                if self.rsi[0] > 85:
                    self.order = self.sell()

            # Выход из Short
            elif self.position.size < 0:
                if self.rsi[0] < 15:
                    self.order = self.buy()
```

---

## 4. Важные замечания

- **Инкапсуляция параметров** — все периоды и уровни выносить в `params`. Это обязательно для последующей оптимизации через Optuna
- **Скрытая логика индикаторов** — RSI по умолчанию использует `SmoothedMovingAverage` внутри. Можно переопределить, передав свои значения через `params`
- **Закрытие позиций** — встречный ордер (`buy` закрывает шорт, `sell` закрывает лонг). Отдельных функций отмены не нужно
- **Всегда через `self`** — объекты индикаторов должны быть атрибутами класса (`self.sma = ...`), иначе движок не будет их пересчитывать

## 6. Применение в боте (T-Invest API)

- **Вычисления в движке** — загружаем исторические свечи из T-Invest в Backtrader, инициализируем индикаторы в `__init__`. При трансляции новых тиков по WebSocket движок пересчитывает значения автоматически
- **Кроссы как триггеры** — `CrossOver` избавляет от хранения массивов прошлых цен. Как только `self.cross_up_rsi[0] == 1` — бот формирует API-запрос к T-Invest на выставление ордера
- **Контроль направления позиции** — `self.position.size > 0 / < 0` не позволит открыть второй лонг поверх первого и упростит реализацию реверсивных систем
