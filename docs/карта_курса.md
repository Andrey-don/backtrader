## Дорожная карта проекта (наш план)

```
Этап 1: Backtrader (бэктестинг)
  └─ Изучить уроки 01–16 модуля 01
  └─ Построить базовый шаблон стратегии

Этап 2: Машинное обучение
  └─ Изучить модуль 02
  └─ Интегрировать ML-сигналы в стратегию

Этап 3: Оптимизация (Optuna)
  └─ Автоматический перебор параметров

Этап 4: Live-торговля через T-Invest API
  └─ Изучить модуль 04 (Т-Банк)
  └─ Адаптировать бэктест-стратегию к live
  └─ Сначала — Sandbox (тест с виртуальными деньгами)
  └─ Потом — реальный счёт

Этап 5: Мониторинг и масштабирование
  └─ Сервер для бота сигналов (модуль 08)
  └─ Расширение на другие биржи
```
