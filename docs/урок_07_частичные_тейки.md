# Урок 07: Частичные тейки в Backtrader

## 1. Краткое резюме

Урок посвящён выставлению нескольких тейк-профитов на одну позицию — частичному закрытию по уровням. Показано, как через `bt.Order.Limit` зафиксировать часть позиции на первом тейке (50%) и оставшуюся часть на втором, а через `bt.Order.Stop` выставить стоп-лосс. Все три ордера отправляются одновременно сразу после открытия позиции.

---

## 2. Ключевые концепции

- **`bt.Order.Limit`** — лимитный ордер: исполняется по указанной цене или лучше. Используется для тейк-профитов
- **`bt.Order.Stop`** — стоп-ордер: становится рыночным, когда цена достигает указанного уровня. Используется для стоп-лосса
- **Частичное закрытие** — `self.sell(size=..., exectype=bt.Order.Limit, price=...)` — продаёт только указанное количество, не всю позицию
- **Размер для частичного закрытия** — берётся как доля от текущей позиции: `self.broker.getposition(self.data).size * 0.5`

---

## 3. Код урока

```python
import backtrader as bt


class TestStrategy(bt.Strategy):
    params = dict(
        stop_loss=0.02,  # 2% стоп-лосс
        tp1=0.02,        # 2% первый тейк-профит
        tp2=0.05         # 5% второй тейк-профит
    )

    def __init__(self):
        self.order = None

    def next(self):
        if self.order:
            return

        # Покупка по простому условию
        if self.data.close[0] > self.data.close[-1]:
            self.order = self.buy()
            entry_price = self.data.close[0]

            # Расчёт уровней
            tp1_price = entry_price * (1 + self.params.tp1)
            tp2_price = entry_price * (1 + self.params.tp2)
            stop_price = entry_price * (1 - self.params.stop_loss)

            # Первый тейк-профит — 50% позиции
            self.sell(
                size=self.broker.getposition(self.data).size * 0.5,
                exectype=bt.Order.Limit,
                price=tp1_price
            )

            # Второй тейк-профит — оставшиеся 50%
            self.sell(
                size=self.broker.getposition(self.data).size * 0.5,
                exectype=bt.Order.Limit,
                price=tp2_price
            )

            # Стоп-лосс
            self.sell(exectype=bt.Order.Stop, price=stop_price)

    def notify_order(self, order):
        if order.status in [order.Completed]:
            if order.isbuy():
                print(f"Куплено по {order.executed.price}")
            elif order.issell():
                print(f"Продано по {order.executed.price}")
```

---

## 4. Важные замечания

- **Размер позиции при выставлении** — в момент отправки ордеров `self.broker.getposition(self.data).size` может быть 0, так как основной ордер ещё не исполнен. Лучше рассчитывать размер явно через `stake` или `PercentSizer`
- **Конкуренция ордеров** — если сработал стоп, лимитные тейки надо отменять через `self.cancel(order)`, иначе они останутся висеть
- **`exectype` по умолчанию** — если не указывать `exectype`, ордер исполнится по цене открытия следующего бара (рыночный)

---

## 5. Шпаргалка

| Действие | Код |
|----------|-----|
| Лимитный ордер на продажу | `self.sell(size=N, exectype=bt.Order.Limit, price=price)` |
| Стоп-ордер на продажу | `self.sell(exectype=bt.Order.Stop, price=stop_price)` |
| Отмена ордера | `self.cancel(order)` |
| Размер текущей позиции | `self.broker.getposition(self.data).size` |

---

## 6. Применение в боте (T-Invest API)

- **Несколько ордеров одновременно** — при открытии позиции сразу отправлять 3 приказа в T-Invest: один лимитный тейк-1, один лимитный тейк-2, один стоп
- **Отмена при срабатывании стопа** — после получения webhook об исполнении стоп-ордера — отменять оставшиеся лимитные тейки через API
- **Частичное закрытие в T-Invest** — API поддерживает указание `quantity` в ордере, что позволяет закрывать только часть позиции
