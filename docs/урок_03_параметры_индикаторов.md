# Урок 03: Параметры индикаторов Backtrader

## 1. Краткое резюме

Урок посвящён правильному вызову встроенных индикаторов в Backtrader и настройке их параметров. На примере RSI, StochasticFull и CCI разбирается, как находить нужные параметры через исходный код на GitHub или встроенную справку `Shift+Tab`. Данные — акции Аэрофлот (AFLT) через moexalgo.

---

## 2. Ключевые концепции

- **Документация через GitHub** — репозиторий Backtrader, папка `indicators`. Атрибут `params` — параметры расчёта, `lines` — названия возвращаемых линий
- **`Shift+Tab`** — в Jupyter выводит справку по индикатору прямо в скобках
- **Передача данных** — `self.datas[0]` — передаём весь объект данных, индикатор сам берёт нужные колонки (OHLCV)
- **Индекс `[0]`** — текущее значение индикатора. Без индекса выводится объект, а не число

---

## 3. Код урока

```python
import backtrader as bt
import pandas as pd
from moexalgo import Ticker


def process_candles(data, ticker_name):
    df = pd.DataFrame(data)
    df.drop(columns=['end'], inplace=True)
    df.rename(columns={'begin': 'datetime'}, inplace=True)
    df['ticker'] = ticker_name
    return df

ticker = 'AFLT'
data = Ticker(ticker).candles(start='2024-05-23', end='2024-07-16', period=60)
df = process_candles(data, ticker)


class TestStrategy(bt.Strategy):
    def log(self, txt, dt=None):
        dt = dt or self.datas[0].datetime.date(0)
        print('%s, %s' % (dt.isoformat(), txt))

    def __init__(self):
        self.dataclose = self.datas[0].close

        # RSI — полное имя: RelativeStrengthIndex
        self.rsi = bt.indicators.RelativeStrengthIndex(self.datas[0], period=14)

        # StochasticFull — lines: percK, percD; params: period, period_dfast, period_dslow
        self.stoch = bt.indicators.StochasticFull(self.datas[0], period_dslow=12)

        # CCI — полное имя: CommodityChannelIndex
        self.cci = bt.indicators.CommodityChannelIndex(self.datas[0], period=14, factor=0.015)

    def next(self):
        print(f"Close: {self.dataclose[0]:.2f}, "
              f"RSI: {self.rsi[0]:.2f}, "
              f"Stoch: {self.stoch[0]:.2f}, "
              f"CCI: {self.cci[0]:.2f}")


if __name__ == '__main__':
    cerebro = bt.Cerebro()
    cerebro.addstrategy(TestStrategy)

    data = df.copy()
    data['datetime'] = pd.to_datetime(data['datetime'])
    data.set_index('datetime', inplace=True)
    cerebro.adddata(bt.feeds.PandasData(dataname=data))

    cerebro.broker.setcash(100000.0)
    print('Стартовый портфель: %.2f' % cerebro.broker.getvalue())
    cerebro.run()
    print('Конечный портфель: %.2f' % cerebro.broker.getvalue())
```

---

## 4. Важные замечания

- **Полные имена** — `RelativeStrengthIndex`, `CommodityChannelIndex` — оба варианта работают (и короткий `RSI`, `CCI`)
- **`period_dslow`** у StochasticFull — не `period_d`. Всегда проверять на GitHub
- **Дефолтные значения** — RSI без `period` использует 14. Для Optuna всегда задавать явно через `params`
- **Вложенные индикаторы** — RSI внутри использует `SmoothedMovingAverage`, что влияет на период прогрева

## 5. Шпаргалка

| Действие | Код |
|----------|-----|
| Встроенная справка | `Shift+Tab` внутри скобок в Jupyter |
| RSI | `bt.indicators.RelativeStrengthIndex(self.datas[0], period=14)` |
| Stochastic Full | `bt.indicators.StochasticFull(self.datas[0], period_dslow=12)` |
| CCI | `bt.indicators.CommodityChannelIndex(self.datas[0], period=14, factor=0.015)` |
| Текущее значение | `self.rsi[0]`, `self.stoch[0]`, `self.cci[0]` |
| Линия stoch | `self.stoch.lines.percD[0]`, `self.stoch.lines.percK[0]` |

## 6. Применение в боте (T-Invest API)

- **Однократная инициализация** — индикаторы объявляются в `__init__`, Backtrader пересчитывает при каждой новой свече
- **RSI < 30 / > 70** — классические уровни для сигналов в боте
- **Знание `params` и `lines`** — позволяет точно настраивать любой индикатор (в т.ч. экзотические) без ошибок
