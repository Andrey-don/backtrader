# Урок М2-07: Стратегии для криптовалют (парный трейдинг / коинтеграция)

## 1. Краткое резюме

Урок посвящён статистическому арбитражу (парному трейдингу). Классические технические индикаторы плохо работают на криптовалютах из-за резких пампов и манипуляций, поэтому автор переходит к стратегии, основанной на математической коинтеграции активов. Несмотря на криптовалютную тематику, алгоритм демонстрируется на акциях технологических компаний (ADBE, MSFT, AAPL) через Yahoo Finance. Суть: найти два исторически связанных актива и торговать их спредом в моменты сильных статистических отклонений.

---

## 2. Ключевые концепции

- **Стационарность** — свойство ряда, при котором значения колеблются вокруг постоянного среднего с неизменным размахом.
- **Нестационарность** — ряд с выраженным трендом и изменяющейся дисперсией (большинство цен активов).
- **Коинтеграция** — наличие долгосрочного равновесного отношения между двумя нестационарными рядами. Даже если активы локально расходятся, они возвращаются к равновесному среднему.
- **Корреляция vs коинтеграция** — активы могут иметь корреляцию 0.99, но нулевую коинтеграцию. Для парного трейдинга нужна именно коинтеграция.
- **Спред** — разница между ценами двух коинтегрированных активов.
- **Z-оценка (Z-score)** — приведение спреда к стандартному распределению (среднее=0, σ=1). Выход за ±1 — торговый сигнал.
- **Тест Дики-Фуллера (ADF)** — статистический тест на стационарность ряда.

```python
import numpy as np
import pandas as pd
from statsmodels.tsa.stattools import adfuller, coint

# === БЛОК 1: Тест Дики-Фуллера на стационарность ===
def stationarity_test(X, cutoff=0.01):
    pvalue = adfuller(X)[1]  # исправлено: было [16]
    if pvalue < cutoff:
        print(f'p-value = {pvalue}. Ряд {X.name} вероятно стационарен.')
    else:
        print(f'p-value = {pvalue}. Ряд {X.name} вероятно нестационарен.')

# === БЛОК 2: Поиск коинтегрированных пар ===
def find_cointegrated_pairs(data):
    n = data.shape[1]  # исправлено: было [16]
    score_matrix = np.zeros((n, n))
    pvalue_matrix = np.ones((n, n))
    keys = data.keys()
    pairs = []
    for i in range(n):
        for j in range(i + 1, n):
            S1 = data[keys[i]]
            S2 = data[keys[j]]
            result = coint(S1, S2)
            score = result[0]
            pvalue = result[1]  # исправлено: было [16]
            score_matrix[i, j] = score
            pvalue_matrix[i, j] = pvalue
            if pvalue < 0.05:
                pairs.append((keys[i], keys[j]))
    return score_matrix, pvalue_matrix, pairs

# === БЛОК 3: Расчёт Z-оценки ===
def zscore(series):
    return (series - series.mean()) / np.std(series)

# === БЛОК 4: Симуляция торговой стратегии (парный трейдинг) ===
def trade(S1, S2, window1, window2):
    if (window1 == 0) or (window2 == 0):
        return 0

    ratios = S1 / S2
    ma1 = ratios.rolling(window=window1, center=False).mean()
    ma2 = ratios.rolling(window=window2, center=False).mean()
    std = ratios.rolling(window=window2, center=False).std()
    zscore = (ma1 - ma2) / std

    money = 0
    countS1 = 0
    countS2 = 0

    for i in range(len(ratios)):
        if zscore[i] < -1:          # спред слишком мал → продаём соотношение
            money += S1[i] - S2[i] * ratios[i]
            countS1 -= 1
            countS2 += ratios[i]
        elif zscore[i] > 1:         # спред слишком велик → покупаем соотношение
            money -= S1[i] - S2[i] * ratios[i]
            countS1 += 1
            countS2 -= ratios[i]
        elif abs(zscore[i]) < 0.75: # возврат к среднему → закрываем позиции
            money += S1[i] * countS1 + S2[i] * countS2
            countS1 = 0
            countS2 = 0

    return money
```

## 4. Важные замечания

- **Крипта vs MOEX** — классические индикаторы ломаются на крипте из-за пампов. Коинтеграция даёт более устойчивую математическую основу.
- **Волатильность на крипте** — Z-score может уходить выше 5 перед возвратом к норме. Требует большого запаса маржи. На MOEX крупные акции ходят плавнее.
- **Часы торгов** — MOEX: клиринги, выходные, гэпы на открытии. Код должен обрабатывать разрывы. Крипта: 24/7, более гладкие ряды для скользящих средних.
- **Комиссии и funding rate** — на бессрочных фьючерсах Bybit/Binance каждые 8 часов списывается ставка финансирования, которая может съесть всю прибыль. На MOEX — фиксированная ставка брокера за перенос шорта через ночь.
- **Маркет-нейтральность** — стратегия идеальна для бокового и падающего рынка: убыток по лонгу перекрывается прибылью по шорту.

## 6. Применение в торговом боте (T-Invest / MOEX)

**Поиск пар на MOEX:**
- Регулярно парсить историю акций одного сектора: Лукойл/Роснефть, SBER/SBERP (обычные и привилегированные)
- Прогонять через `find_cointegrated_pairs()` для выявления математически связанных пар

**Логика исполнения:**
1. Рассчитать Z-score спреда в реальном времени
2. Z-score > +2 → продать актив A (переоценён), купить актив B (недооценён) через T-Invest API
3. Z-score < −2 → купить A, продать B
4. Z-score < 0.5 → закрыть обе позиции, зафиксировать прибыль

**Преимущество на MOEX:** в боковике и при обвале рынка стратегия работает — убыток по лонгу компенсируется шортом. Классические трендовые стратегии в таких условиях сливают.
