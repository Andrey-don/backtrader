# Урок М2-03: Тест Гренджера

## 1. Краткое резюме

Тест Гренджера — это статистический метод для определения направления причинно-следственных связей между двумя различными временными рядами. В контексте машинного обучения для трейдинга он является мощным инструментом отбора признаков: тест позволяет математически доказать, содержит ли история цен одного актива (например, «поводыря» или индекса) полезную информацию для предсказания будущих цен целевого инструмента. Это помогает отсеять рыночный шум и оставить в модели только реально работающие данные.

---

## 2. Ключевые концепции

- **Причинность по Гренджеру (Granger Causality)** — гипотеза о том, что прошлые значения одного ряда (X) могут помочь точнее предсказать текущие или будущие значения другого ряда (Y).
- **Лаг (Lag)** — временной сдвиг (количество прошлых дней/баров), на глубину которого алгоритм ищет закономерности и причинно-следственные связи.
- **P-value (P-значение)** — метрика статистической значимости. Показывает вероятность того, что найденная связь случайна. Чем ниже значение, тем сильнее доказательство того, что связь реальна.
- **Кросс-корреляционная функция (Cross-Correlation Function)** — метод, позволяющий найти точку максимальной линейной корреляции между двумя активами с учётом временного сдвига (лага). Помогает понять, не запаздывает ли один актив за другим.

## 3. Код урока

```python
# === БЛОК 1: Загрузка и подготовка данных ===
import yfinance as yf
import pandas as pd

tickers = ['AAPL', 'MSFT', 'GOOGL', 'AMZN', 'TSLA']
df = pd.DataFrame()

for ticker in tickers:
    data = yf.download(ticker, start='2023-01-01', end='2024-01-01')
    df[ticker] = data['Close']

df.head()

# === БЛОК 2: Тест причинности Гренджера ===
from statsmodels.tsa.stattools import grangercausalitytests

granger_frame = pd.DataFrame()
granger_lags = 20  # максимальное количество лагов

for i in df:
    try:
        P_val = []
        for j in range(1, granger_lags + 1):
            # p-value из F-теста на каждом лаге
            P_val.append(
                grangercausalitytests(df[['AAPL', i]], maxlag=[j], verbose=False)[j]['ssr_ftest'][1]
            )
        granger_frame[i] = P_val
    except:
        print(f'Empty - {i}')
        continue

granger_frame.iloc[:, 1:]  # таблица p-value: строки = лаги, столбцы = тикеры

# Единичный тест с полным отчётом: влияет ли MSFT на AAPL
grangercausalitytests(df[['AAPL', 'MSFT']], maxlag=3)

# Обратный тест: влияет ли AAPL на MSFT
grangercausalitytests(df[['MSFT', 'AAPL']], maxlag=3)

# === БЛОК 3: Кросс-корреляционная функция ===
import matplotlib.pyplot as plt
import numpy as np
from scipy import signal

def ccf_values(series1, series2):
    p = series1
    q = series2
    p = (p - np.mean(p)) / (np.std(p) * len(p))
    q = (q - np.mean(q)) / np.std(q)
    c = np.correlate(p, q, 'full')
    return c

ccf_result = ccf_values(df['AAPL'], df['MSFT'])
ccf_result[0:15]
```

## 4. Важные замечания

- **Индексы и даты** — колонка Date не должна восприниматься как числовой признак. Устанавливать как индекс или удалять перед передачей в модель.
- **Двунаправленная проверка** — если актив A предсказывает актив B, обязательно делать обратный тест (B → A). Причинно-следственная связь часто асимметрична.
- **Порог значимости** — классический порог p-value < 0.05. В шумных финансовых рядах допускается брать признаки со значимостью до 0.1.

## 6. Применение в торговом боте (T-Invest / MOEX)

Тест Гренджера — первичный фильтр для подготовки датасета перед подачей данных в ML-модели (CatBoost, XGBoost).

**Пример для MOEX:** бот торгует акциями Сбербанка. Собираем историю потенциальных факторов: нефть, индекс RGBI (гособлигации), фьючерс Si (доллар-рубль), индекс IMOEX. Прогоняем тест Гренджера для каждой пары «Сбербанк — [Фактор]».

**Выводы из p-value:**
- p-value RGBI на лаге 2 = 0.02 (< 0.05) → оставить в датасете
- p-value нефти = 0.85 → удалить, только добавляет шум

**Порядок работы:**
1. Собрать кандидатов-факторов (индексы, коррелирующие активы, макро)
2. Прогнать тест Гренджера для каждого (maxlag=5–20 дней)
3. Оставить только те признаки, где p-value < 0.05 хотя бы на одном лаге
4. Передать отфильтрованный датасет в CatBoost/XGBoost
