# Урок М2-01: Вводное машинное обучение

## 1. Краткое резюме

В данном уроке изучаются основы машинного обучения (ML) — набора математических формул и параметров, с помощью которых машина находит паттерны и обобщает данные для предсказания реальных результатов. Для торгового бота это необходимо, так как ML позволяет анализировать тысячи различных финансовых инструментов одновременно и находить неочевидные взаимосвязи для прогнозирования движения цены актива.

---

## 2. Ключевые концепции

- **Машинное обучение** — процесс подбора параметров математической функции (модели) для максимально точного описания реальных данных и предсказания будущих результатов.
- **train_test_split** — разделение данных на тренировочную (70%) и тестовую (30%) части. На тренировочной модель обучается, на тестовой — проверяется.
- **Линейная регрессия** — модель, описывающая взаимосвязь между переменными с помощью прямой линии.
- **Коэффициент (вес) и свободный член (константа)** — коэффициент показывает степень влияния признака на результат; свободный член — базовое значение при X=0.
- **MSE / RMSE** — среднеквадратичная ошибка. Метрика качества модели: расстояние между реальным и предсказанным значением.
- **R² (R-квадрат)** — показатель уверенности модели. Показывает, на сколько % модель объясняет изменение целевой переменной.
- **Ансамбли моделей (Random Forest, XGBoost, CatBoost, LightGBM)** — нелинейные методы на основе деревьев решений. Лучше справляются с рыночными данными, чем линейные модели.
- **ACF и PACF** — автокорреляционные функции. Показывают, насколько прошлые цены влияют на текущую.
- **RFE (Recursive Feature Elimination)** — метод рекурсивного отбора признаков. Определяет какие фичи реально полезны, а какие добавляют шум.

## 4. Код урока

```python
import warnings
warnings.filterwarnings('ignore')
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error
import statsmodels.api as sm

# === ЧАСТЬ 1: Генерация случайных чисел и обучение модели ===
np.random.seed(42)
X = 2 * np.random.rand(100, 1)
y = 4 + 3 * X + np.random.randn(100, 1)

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

model = LinearRegression()
model.fit(X_train, y_train)

y_pred = model.predict(X_test)
mse = mean_squared_error(y_test, y_pred)
print(f"Среднеквадратичная ошибка: {mse}")
print("Коэффициенты (веса):", model.coef_)
print("Свободный член:", model.intercept_)

# === ЧАСТЬ 2: Датасет зарплат (Statsmodels) ===
data = pd.read_csv("Salary_Data.csv")
X_sm = sm.add_constant(data['YearsExperience'])
y_sm = data['Salary']
model_sm = sm.OLS(y_sm, X_sm).fit()
print(model_sm.summary())

# === ЧАСТЬ 3: Множественная регрессия на студентах ===
df = pd.read_csv("Student_Performance.csv")
df = df.drop('Extracurricular Activities', axis=1)
X_stud = sm.add_constant(df.drop('Performance Index', axis=1))
y_stud = df['Performance Index']
model_stud = sm.OLS(y_stud, X_stud).fit()
print(model_stud.summary())

# === ЧАСТЬ 4: Прогнозирование временных рядов (финансовые данные) ===
data_fin = pd.read_csv("fin_data.csv")
data_fin = data_fin[['Close']]
data_fin['Target'] = data_fin['Close'].shift(-1)  # предсказываем следующий бар
data_fin = data_fin.dropna()

X_fin = data_fin.iloc[:, :1]
y_fin = data_fin.iloc[:, 1:]

# ВАЖНО: для временных рядов — только последовательное разделение, не случайное!
split_index = int(len(X_fin) * 0.8)
X_train_fin, X_test_fin = X_fin[:split_index], X_fin[split_index:]
y_train_fin, y_test_fin = y_fin[:split_index], y_fin[split_index:]

regressor = LinearRegression()
regressor.fit(X_train_fin, y_train_fin)
y_pred_test = regressor.predict(X_test_fin)
```

## 5. Важные замечания

- **Data Leakage (утечка данных)** — при работе с временными рядами категорически нельзя делить данные случайно (через `random_state`). Только последовательное разделение: 80% обучение, 20% тест.
- **Запаздывание модели** — линейная регрессия на ценах просто повторяет график со сдвигом на 1 бар. Такая модель бесполезна для заработка.
- **Мусорные признаки** — добавление шумных данных ухудшает качество модели. 80% времени уходит на подготовку данных. Использовать RFE для отбора признаков.

## 6. Шпаргалка

| Действие | Код |
|---|---|
| Случайное разделение | `train_test_split(X, y, test_size=0.3, random_state=42)` |
| Последовательное разделение (для цен) | `split_index = int(len(X) * 0.8); X_train = X[:split_index]` |
| Создать и обучить модель | `model = LinearRegression(); model.fit(X_train, y_train)` |
| Предсказание | `y_pred = model.predict(X_test)` |
| MSE | `mean_squared_error(y_test, y_pred)` |
| Добавить константу (Statsmodels) | `X = sm.add_constant(data['колонка'])` |
| Сдвиг ряда на 1 шаг вперёд | `data['Target'] = data['Close'].shift(-1)` |

## 7. Применение в торговом боте (T-Invest API / MOEX)

1. **Подготовка фичей** — парсить исторические данные (OHLCV) + добавить технические индикаторы (EMA, RSI, MACD) как дополнительные столбцы.
2. **Таргет** — `shift(-1)` на колонку Close: модель учится предсказывать цену следующего бара.
3. **Отбор признаков** — RFE определяет какие индикаторы реально влияют на цену, а какие шум.
4. **Выбор алгоритма** — линейную регрессию для торгов не использовать из-за запаздывания. Интегрировать CatBoost или XGBoost — они лучше сопротивляются переобучению и точнее предсказывают ценовые паттерны.
