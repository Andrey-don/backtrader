# Урок М2-04: Нейронные сети и их применение

## 1. Краткое резюме

В данном уроке рассматривается применение глубокого обучения для анализа временных рядов в трейдинге: рекуррентные сети (LSTM), одномерные сверточные сети (Conv1D) и простые полносвязные сети (перцептрон). Главная цель нейросети в торговом боте — на основе окна (последовательности) исторических данных (например, цен закрытия за прошлые N дней) предсказать будущее значение (цену закрытия или минимум следующего бара).

---

## 2. Ключевые концепции

- **Sequential (последовательная архитектура)** — способ построения нейросети в Keras, при котором слои добавляются друг за другом.
- **LSTM (Long Short-Term Memory)** — тип рекуррентной сети с «короткой и длинной памятью». Способна запоминать временные зависимости между прошлыми и текущими ценами.
- **Conv1D (сверточная сеть)** — использует фильтры для выделения паттернов в последовательности. На небольших объёмах данных часто показывает результат лучше, чем LSTM.
- **Dense (полносвязный слой / перцептрон)** — каждый нейрон связан со всеми нейронами предыдущего слоя. Хорош когда данных мало.
- **Epochs (эпохи)** — количество полных проходов алгоритма обучения по тренировочному набору данных.
- **Batch Size** — количество примеров, подаваемых в сеть за один раз перед обновлением весов.
- **Input Shape** — входная размерность: `[количество_лагов, количество_признаков]`.
- **Lookback** — размер окна прошлых баров, подаваемых на вход сети.

## 4. Важные замечания

- **Голод до данных** — LSTM требует огромных датасетов. Даже 20 000 строк может быть недостаточно. На маленьких выборках сеть не находит стабильный паттерн.
- **Таймфреймы** — для нейросетей уходить с дневных графиков (D1) на H4, H1 или минуты. Только там достаточно данных.
- **Опасность аугментации** — искусственное размножение финансовых данных не рекомендуется: можно сгенерировать нереалистичные рыночные ситуации.
- **Парадокс простых моделей** — если данных мало, сложная LSTM покажет результат хуже, чем простой перцептрон. Простой алгоритм требует меньше данных для настройки весов.
- **Баги в коде урока** — `shape[13]`, `shape[14]` — OCR-артефакты, должно быть `shape[1]`, `shape[2]`. `[15-17]` в param_grid — не список, а вычисление (равно `[2]`). Исправлено выше.
- **`KerasRegressor` устарел** — в новых версиях TensorFlow/Keras заменён на `scikeras.wrappers.KerasRegressor`.

## 6. Применение в торговом боте (T-Invest / MOEX)

**Когда использовать нейросети:** только для высокочастотного трейдинга (скальпинг) или интрадей на минутных/часовых свечах. Только там будут сотни тысяч строк, нужных для LSTM.

**Когда лучше CatBoost / XGBoost:** для свинговой и среднесрочной торговли на дневных графиках. За 10 лет истории MOEX — около 2500 рабочих дней. Нейросети катастрофически мало. Бустинги лучше сопротивляются переобучению на малых выборках.

**Интеграция в стратегию:**
1. Нарезать технические индикаторы и прошлые цены через `lookback` (например, 10 прошлых часов)
2. Если модель предсказывает Low следующего часа значительно ниже текущей цены → лимитная заявка в этой зоне
3. Если Close прогнозируется выше → вход в лонг по рынку
4. Подбирать `batch_size` и `epochs` через GridSearchCV под каждый актив
