# Урок М2-08: Для чего добавляем константы в ML

## 1. Краткое резюме

Константа (свободный член) в ML-моделях — это базовое значение целевой переменной при условии, что все предикторы равны нулю. Добавление константы необходимо для смещения линии регрессии по оси Y, что обеспечивает гибкость подгонки под реальные данные, предотвращает ошибки в оценке параметров и защищает от неправильной интерпретации результатов.

---

## 2. Ключевые концепции

- **Константа (C или b)** — точка пересечения линии регрессии с осью Y. Показывает базовое/минимальное значение (например, минимальная зарплата при нулевом опыте).
- **Смещение модели** — ошибка при отсутствии константы. Линия прогноза принудительно проходит через (0,0), что криво описывает реальное распределение данных.
- **OLS (метод наименьших квадратов)** — создаёт систему уравнений для каждой точки и минимизирует суммарную ошибку, находя оптимальные константу и коэффициенты.
- **Интерполяция (линейная / сплайн)** — заполнение NaN перед обучением. Линейная: соединяет точки прямой. Кубическая: сглаженная кривая.

---

## 3. Код урока

### Добавление константы (Statsmodels)

```python
import statsmodels.api as sm
import pandas as pd

X = data['YearsExperience']
y = data['Salary']

# Явное добавление константы — без этого линия идёт через (0,0)
X_sm = sm.add_constant(X)

model = sm.OLS(y, X_sm).fit()
print(model.summary())
# В выводе 'const' — вычисленное базовое смещение
```

### Заполнение пропусков (DataFrameProcessor)

```python
# Перед подачей в ML-модель — обязательная обработка NaN
if self.imput_linear == True:
    self.df_combined = self.df_combined.interpolate(method='linear')   # прямая между точками
elif self.imput_linear == False:
    self.df_combined = self.df_combined.interpolate(method='cubic')    # сглаженный сплайн
```

---

## 4. Важные замечания

- **Когда константа обязательна** — практически всегда. В реальной жизни целевая переменная крайне редко равна нулю при нулевых вводных (цены, зарплаты, издержки).
- **Когда константу исключать** — только если теоретически доказано: при X=0 результат Y физически обязан быть строго 0. В финансах такие случаи редки.
- **Типичная ошибка** — отказ от константы заставляет признаки X «впитывать» недостающее смещение → коэффициенты искажаются → прогноз неадекватен.
- **Важно:** XGBoost и CatBoost не требуют явного `add_constant` — они сами находят смещения. `sm.add_constant` нужен только для statsmodels (OLS, Logit, и т.д.).

---

## 5. Шпаргалка

| Действие | Функция / Параметр |
|---|---|
| Явное добавление константы | `sm.add_constant(X)` |
| Обучение модели OLS | `sm.OLS(y, X).fit()` |
| Значение константы (sklearn) | `model.intercept_` |
| Заполнение NaN прямой | `df.interpolate(method='linear')` |
| Заполнение NaN сплайном | `df.interpolate(method='cubic')` |

---

## 6. Применение в торговом боте (T-Invest / MOEX)

- **Statsmodels (OLS, тест Гренджера)** → обязательно `sm.add_constant(X)` перед обучением. Константа отражает базовый уровень цены/спреда, от которого модель считает отклонения.
- **XGBoost / CatBoost** → `add_constant` не нужен. Алгоритмы сами находят нелинейные зависимости и базовые смещения.
- **Практическое правило:** statsmodels = явная константа, sklearn/бустинги = без константы.
