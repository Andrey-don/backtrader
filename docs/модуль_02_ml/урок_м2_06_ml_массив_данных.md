# Урок М2-06: Машинное обучение на массиве данных

## 1. Краткое резюме

«ML на массиве данных» — использование котировок множества активов в качестве независимых признаков (предикторов) для прогнозирования движения цены одного целевого инструмента (таргета). Вместо анализа только прошлого самого актива, модель ищет скрытые корреляции между широким спектром бумаг (например, 45 акциями из разных секторов) и целевой акцией, чтобы предсказать её будущую стоимость.

---

## 2. Ключевые концепции

- **Таргет и предикторы** — таргет: актив, цену которого предсказываем (CSX). Предикторы: массив остальных акций как фичи.
- **Ансамбль комбинаций (Ensemble)** — объединение предсказаний нескольких топовых моделей (CatBoost, XGBoost, LightGBM). Если одна ошибается, другая компенсирует.
- **Mutual Information** — нелинейный отбор признаков (`mutual_info_regression`). Оценивает зависимость между предиктором и таргетом.
- **Импутация (Linear / Cubic Interpolation)** — заполнение NaN при слиянии графиков разных активов (из-за рассинхронизации торговых дней).
- **Isolation Forest** — поиск аномалий (выбросов) в рядах. Выбросы зануляются, затем интерполируются.
- **SES / DES (экспоненциальное сглаживание)** — SES выделяет тренд, DES (Хольта-Винтерса) учитывает и тренд, и его направление.
- **Фильтр Калмана / FFT** — продвинутые методы очистки ряда. Калман — для линейных гауссовских шумов, FFT — для сезонных и частотных колебаний.

```python
import yfinance as yf
import pandas as pd
from datetime import datetime, timedelta

stocks_list = [
    "AAPL", "MSFT", "GOOG", "AMZN", "FB", "TSLA", "NVDA", "NFLX", "PYPL", "ADBE",
    "INTC", "CSCO", "CMCSA", "PEP", "COST", "TMUS", "AVGO", "TXN", "QCOM", "SBUX",
    "AMD", "CHTR", "INTU", "AMGN", "MU", "BKNG", "ISRG", "GILD", "VRTX", "MDLZ",
    "FISV", "ADP", "REGN", "BIIB", "ZM", "MRNA", "ATVI", "CSX", "JD", "AMAT", "ADI",
    "EA", "LRCX", "DXCM", "EXC"
]

all_stocks_close = pd.DataFrame()
end_date = datetime.today()
start_date = end_date - timedelta(days=300)

for stock in stocks_list:
    try:
        stock_data = yf.download(stock, start=start_date, end=end_date)
        all_stocks_close[stock] = stock_data['Close']
    except Exception as e:
        print(f"Не удалось загрузить {stock}: {e}")

all_stocks_close = all_stocks_close.reset_index()

# Разделение на предикторы и таргет
predictors = all_stocks_close.drop('CSX', axis=1).copy()
target = all_stocks_close[['Date', 'CSX']]

target.to_csv('target.csv', index=False)
predictors.to_csv('predictors.csv', index=False)
```

### Блок 2: Очистка и слияние (DataFrameProcessor)

```python
import pandas as pd
import numpy as np

class DataFrameProcessor:
    def __init__(self, df_predictors, df_target, columns_predictors, constants):
        self.df_predictors = df_predictors
        self.df_target = df_target
        self.columns_predictors = columns_predictors
        self.constants = constants

    def process_data(self):
        threshold = self.constants.get('threshold')
        # Удаление столбцов с большим количеством пропусков
        self.df_predictors = self.df_predictors.dropna(
            thresh=len(self.df_predictors) - round(len(self.df_predictors) * threshold), axis=1
        )
        imput_linear = self.constants.get('imput_linear')
        if imput_linear:
            self.df_predictors = self.df_predictors.interpolate(method='linear')
        else:
            self.df_predictors = self.df_predictors.interpolate(method='cubic')

    def merge_dfs(self):
        self.df_combined = pd.merge(self.df_target, self.df_predictors, how='left', on='date')
        imput_linear = self.constants.get('imput_linear')
        if imput_linear:
            self.df_combined = self.df_combined.interpolate(method='linear')
        else:
            self.df_combined = self.df_combined.interpolate(method='cubic')
        self.df_combined = self.df_combined.dropna().reset_index(drop=True)
```

### Блок 3: Отбор признаков и аномалий (FeaturesSelection)

```python
from sklearn.feature_selection import mutual_info_regression, SelectPercentile
from sklearn.ensemble import IsolationForest
from sklearn.preprocessing import StandardScaler

class FeaturesSelection:
    def __init__(self, df, constants):
        self.df = df
        self.constants = constants

    def last_corr(self):
        ls_corr = self.constants.get('ls_corr')
        X_mut = self.df.drop(['date', 'Target'], axis=1)[:-2]
        y_mut = self.df.Target.shift(2).dropna().reset_index(drop=True)

        selector = SelectPercentile(mutual_info_regression, percentile=ls_corr)
        selector.fit(X_mut, y_mut)
        high_corr_cols = self.df.drop(['date', 'Target'], axis=1).columns[selector.get_support()].tolist()
        self.df = self.df[['date', 'Target'] + high_corr_cols]

    def anomaly_fighter(self):
        scaler = StandardScaler()
        np_scaled = scaler.fit_transform(self.df['Target'].values.reshape(-1, 1))

        model = IsolationForest(n_estimators=10, contamination=0.03)
        model.fit(np_scaled)
        self.df['Isol'] = model.predict(np_scaled)

        # Зануление выбросов + интерполяция
        self.df['Target'] = np.where(self.df['Isol'] != -1, self.df['Target'], np.nan)
        self.df = self.df.drop('Isol', axis=1)
        self.df['Target'] = self.df['Target'].interpolate(method='linear')
```

## 4. Важные замечания

- **Защита от переобучения** — если после всех фильтров (Гренджер + кросс-корреляция + Mutual Information) в модели остаётся менее 3 активов-предикторов → модель отбраковывается (`optuna.TrialPruned()`). Мало фичей = неустойчивая модель.
- **Длительность расчётов** — при 18 моделях и комбинациях по 14 получается 3060 комбинаций. Бэктест на глубокой истории займёт часы. На этапе тестирования брать окно 25–50 дней.
- **Логика бэктеста** — оценка ансамбля по среднему предсказанию топ-комбинаций. Строится бинарный вектор: цена вверх (1) или вниз (0) относительно прогноза.
- **Демо на американских акциях** — для MOEX нужно заменить тикеры на российские и использовать MOEXALGO вместо yfinance.

## 6. Применение в торговом боте (T-Invest / MOEX)

**Пайплайн для среднесрочной торговли на D1:**

1. **Парсинг** — ежедневно/еженедельно скачивать свечи: таргет (Сбербанк) + 40–50 предикторов (другие банки, нефть, IMOEX, RGBI, Si)
2. **Очистка** — Isolation Forest на таргете, интерполяция пропусков в предикторах
3. **Отбор признаков** — SelectPercentile по Mutual Information, оставить топ-фичи
4. **Обучение** — раз в месяц обучить CatBoost + XGBoost + LightGBM, взять топ по R²
5. **Ансамбль** — перебрать комбинации, выбрать лучшую по бэктесту на окне 25–50 дней
6. **Торговля** — если ансамбль предсказывает рост завтра → Market Buy через T-Invest API, если падение → закрыть позицию или шорт
