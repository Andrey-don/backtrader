# Урок М2-02: Источники данных для ML

## 1. Краткое резюме

Для обучения ML-моделей нужен большой объём качественных исторических данных. В этом уроке рассматриваются три источника для автоматизированного сбора котировок за периоды от 1 до 10 лет. Сформированные датасеты используются для обучения алгоритмов предсказывать движение цен перед запуском бота в реальные торги.

---

## 2. Ключевые концепции

- **Bybit (pybit)** — получение данных с криптовалютной биржи через API. Свечи любых интервалов, фьючерсы и спот.
- **MOEXALGO** — библиотека Московской биржи. История торгов по российским акциям за многолетний период.
- **TradingView (кастомный лоадер)** — доступ к склеенным фьючерсам и индексам. До 10 лет истории по фьючерсам Мосбиржи через формат брокера ALOR.

## 4. Важные замечания

- **API ключи Bybit** — обязательно генерировать `api_key` и `api_secret`. Параметр `category`: `linear` — фьючерсы, `spot` — спот.
- **Rate Limits** — при парсинге многих тикеров ставить паузу `delay=1` в цикле, иначе биржа заблокирует IP.
- **Пропуски в данных MOEX** — выходные и праздники создают NaN. Обязательно заполнять через `fillna(method='ffill')`, иначе ML-модели дадут ошибку или искажённый результат.
- **Синтаксис TradingView** — для склеенных фьючерсов: приставка `ALOR:` + суффикс `1!` (например, `ALOR:RI1!`).

## 5. Шпаргалка

| Источник | Биржа | Ключевая функция | Для кого |
|---|---|---|---|
| pybit | Bybit (крипта) | `HTTP`, `category='linear'/'spot'` | Криптотрейдеры |
| MOEXALGO | Московская биржа | `Ticker`, история 365×5 дней | Акции РФ |
| TradingView | Любые рынки | `load_asset_price(symbol, 3650, "1D", None)` | Фьючерсы РФ до 10 лет |

## 6. Применение в торговом боте (T-Invest / MOEX)

**Для бота на акциях MOEX:** использовать **MOEXALGO** — бесплатно, официально, 5 лет истории, широкий пул российских акций (Сбер, Лукойл, Газпром и др.).

**Для бота на фьючерсах MOEX (Ri, Si, BR, SR):** обязательно **TradingView** — фьючерсы экспирируют каждые 3 месяца, нужна склеенная непрерывная история за 5-10 лет. Тикеры с суффиксом `1!` дают правильно склеенный ряд.

**T-Invest API** — для получения свежих данных в реальном времени, но не для глубокой истории. Комбинировать: MOEXALGO/TradingView для обучения ML + T-Invest для live-торговли.
